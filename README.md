# 小組分享計時

小組分享用的倒數計時 PWA。純靜態 HTML / CSS / JS，無需建置、無外部相依，可離線使用。

## 畫面配置（由上到下）
0. **頂端列**：左上角為小組標誌「心成」（`icons/logo.png`，400×120，保持原比例、不變形；平板／筆電約 44–48px 高，手機約 28–30px）；右上角為「☰ 名單／座位／設定」按鈕，按鈕下方小字顯示「已分享 x/y」。
1. **圓形時鐘**（Time Timer 風格）：整圈＝這個人的全部時間。圓內由上而下顯示目前分享者姓名、大字倒數、「剩餘／超時／準備」，以及計時中才出現的「暫停／結束」按鈕。
   - 剩餘時間以從 12 點鐘方向順時針的扇形表示，時間越少扇形越小；剩餘 > 20 秒為綠色、≤ 20 秒為紅色。
   - 0:00 叮咚＋「時間到」後轉為藍色扇形從 0 開始長大，超時 30 秒長滿一圈；之後維持滿圈並繼續顯示 `+mm:ss`（超時期間不再發出任何聲音）。
   - 無人分享時為中性灰色滿圈。
   - 扇形（幾乎）滿圈時直接畫成實心圓，不會在 12 點鐘到圓心出現一條細黑縫（v10 修正 conic-gradient 接縫）。
2. **暫停／繼續、結束** 按鈕（v9 起在**圓內**、狀態文字下方）：白色圓角大按鈕加陰影，在綠／紅／藍扇形上都清楚可按（觸控區至少 48px，iPad 上約 64–72px）。只在計時中（含暫停）出現；暫停後左邊按鈕變成「▶ 繼續」，圓上方顯示「❚❚ 已暫停」。圓下方不再有另一組按鈕，因此時鐘可以更大、下排座位不會被擋住。
3. **每人分享時間** 設定：時鐘式大字 `M:SS` 調整器——分鐘上方「＋」／下方「−」每次 ±1 分，秒數上方「＋」／下方「−」每次 ±5 秒（自動進位／借位，例如 0:55 ＋5 秒 → 1:00；範圍 0:05～59:55）；下方為 3×2 快速選擇（1分、1分30秒、2分、2分30秒、3分、5分）；標題旁「試音量大小」按鈕依實際順序與音量播放所有提示音：「剩下 20 秒」（音量 0.6）→ 短暫停頓 → 叮咚 →「時間到」（皆為音量 1.0），可先確認音量；播放中再按一次會從頭重播、不會重疊。計時中會自動收起，結束後再顯示。
4. **分享名單**（兩欄卡片，依座位順序，名字前顯示座號）：標題列顯示「已分享 x/y」，下方為「編輯名單」與「全部重設」按鈕。

## 提示音
- 剩下 20 秒：語音「剩下 20 秒」（音量 0.6；分享時間需大於 20 秒）
- 0:00：叮咚（最大音量）後接著語音「時間到」（音量 1.0）
- 超時後：不再響鈴或說話，只安靜地繼續顯示 `+mm:ss`
- 語音語速為 1.3 倍（「剩下 20 秒」、「時間到」及試音量大小皆同）
- 每位分享者每個提示只出現一次；若頁面在背景導致提示延遲超過約 5 秒，該提示會略過。
- 語音使用 Web Speech API（優先 zh-TW 語音，否則任何中文語音）；不支援時只會略過語音，計時不受影響。
- iPhone 需要先點一下畫面（任何按鈕）才能解鎖聲音與語音。

## 座位圖（v10：依「邊」排座位；v11：後／左改為 1 在左／上）
圓形時鐘四周是座位圖：每個人坐在 **前／右／後／左** 其中一邊，座號依邊自動編號（前1、前2…、右1…、後1…、左1…）。每一邊的座位數＝坐在那一邊的人數（不限 3 個，也可以是 0 個）。

- **方向與編號**（v11 起，每一邊都是「1 在左／上」）：
  - **前**＝畫面上方，由左到右：前1、前2、前3…
  - **右**＝右側，由上到下：右1、右2…
  - **後**＝下方，**由左到右**（後1 在最左邊，從左看是 後1、後2、後3…）
  - **左**＝左側，**由上到下**（左1 在最上面，從上看是 左1、左2、左3…）
  - v11 只改變後／左在座位圖上的畫法；每個人存的邊與順序不變（舊存檔的後1 仍是後1，只是改畫在最左邊）。
- 每一邊的卡片沿著那一邊**平均分布**，人越多卡片越窄（上下）或越矮（左右）；某一邊特別擠時，上／下排可延伸到兩側角落。沒有人的那一邊就不顯示卡片。
- 左右兩側為直書卡片：姓名大字靠螢幕外側、座號（如「右1」）靠時鐘；上下為寬卡片，姓名大字、下方小字座號（如「前1」）。名字太長會自動縮小字級。
- **面板收合＋「座位圖」開啟**時：座位貼齊螢幕邊緣，時鐘在中間盡量放大；標誌與 ☰ 按鈕不會蓋到上排座位（上排放在兩者之間，放不下時移到它們下方），時鐘不會蓋到任何座位。
- **狀態**：已分享＝變暗；正在分享＝亮框發光，顏色跟時鐘一致（綠／紅／藍）。
- **點座位就開始計時**（面板收合時），規則和點名單上的名字一樣：點灰色（已分享）座位會恢復為未分享；點正在分享的人不會有動作（請用圓內的暫停／結束）。
- 一般名單（非編輯）依座位順序排列：前 → 右 → 後 → 左，名字前顯示座號。
- **「座位圖」開關**：在面板「分享名單」標題旁，只影響非編輯時的畫面（關閉＝只有大時鐘）。設定存在 localStorage（`showSeats`；舊存檔沒有時預設開啟）。非編輯狀態下面板開啟時，座位圖會暫時隱藏。
- **手機**（螢幕短邊小於 560px）空間不足，座位圖自動隱藏；名單與座號照常可用。

### 資料與舊版相容
- 每個人存成 `{ id, name, done, side, seat }`：`side` 為「前／右／後／左」，`seat` 為該邊內的順序（1 起算）；陣列本身也依座位順序（前 → 右 → 後 → 左）儲存。
- **舊版（v9 或沒有 `side`）存檔自動轉換**：依原名單順序，第 1–3 位 → 前、4–6 → 右、7–9 → 後、10–12 → 左；第 13 位起放到**目前人數最少的那一邊**（同樣少時依 前、右、後、左 的順序）。姓名、已分享狀態、`showSeats`、分享時間都會保留。
- 新安裝的預設 12 人名單＝每邊 3 人。
- **新增成員**預設坐到人數最少的那一邊（同樣少時坐前面），排在那一邊的最後。

## 編輯名單（排座位）
按面板中的「✎ 編輯名單」進入。

- **iPad 橫放／筆電**（例如 1180×820、1440×900）：左邊**一定顯示即時座位圖**（就算「座位圖」開關是關的），時鐘縮小（1180×820 約 290px）置中、圓內顯示「編輯中」，座位排在左半邊區域的邊緣，不會和右邊面板重疊；暫停／結束按鈕在編輯時隱藏。
- 右邊是**加大的編輯面板**（方便長輩看）：標題「編輯名單（排座位）」、醒目的「✓ 完成」按鈕，提示「點座號選前右後左，再用 ▲▼ 排順序」。編輯時不顯示分享時間設定。
- 名單**依邊分組**，每組標題如「前（4 人）」。每一列（約 52px 高、姓名約 26–28px 大字）只有一行：**座號按鈕「前1 ▾」**、加寬的姓名欄、▲▼、✕（v11 拿掉列上的前右後左四個小按鈕，姓名欄變寬）。
  - 點 **座號按鈕「前1 ▾」** 會跳出選單「前1 王小明　坐哪一邊？」，四個大按鈕 **前／右／後／左**（目前那一邊為藍色）＋「取消」。iPad／筆電上選單出現在那一列下方（下方放不下時改在上方）；手機或畫面太窄時改成畫面底部的大選單。
  - 選另一邊：這個人移到那一邊的**最後一位**，兩邊座號立即重新編號；選目前那一邊、按「取消」、Esc 或點選單外面都只是關閉。
  - **▲▼ 只在同一邊內**調整前後；每一邊第一位的 ▲、最後一位的 ▼ 不能按。
  - 改名、換邊、調整順序、新增、刪除，左邊座位圖都**立即更新**。
- **選取同步**：點一下（或用鍵盤移到）某一列，座位圖上那個人的座位會**亮黃框**，該列姓名欄也是黃框；反過來，在編輯中**點座位＝選取那一列**（自動捲到那一列），**不會開始計時**。
- 名單很長時面板可以捲動；下方可新增成員（支援注音／拼音，選字的 Enter 不會誤新增或重複新增）。
- 最下方「**成員全部重設**」會跳出確認視窗：「確定清除全部成員？」，下方兩個平分寬度的大按鈕——左「**是**」（紅色，清除全部成員與座位）、右「**否**」（取消）。按 Esc、點視窗外或「否」都會取消；開啟時焦點預設在「否」，Tab 只會在兩個按鈕間切換。
- **iPad 直放**（例如 820×1180）：座位圖在上方、編輯面板在下方。
- **手機**（例如 390×844、320×568）：不顯示座位圖，只有分組名單；每人一行（座號按鈕＋姓名＋▲▼✕；320px 寬的小手機改成兩行：座號＋姓名／▲▼✕），選邊用底部大選單，不會左右超出畫面。
- 按「✓ 完成」或收合面板即結束編輯。

### 可收合的「名單／座位／設定」面板
- 開啟時預設**收合**：畫面為座位圖＋圓形時鐘（座位圖關閉或手機上則只剩時鐘），時鐘會盡量放大填滿畫面，且不會蓋到左上角標誌。
- 按右上角「☰ 名單／座位／設定」開啟面板（時間設定＋名單＋座位圖開關）；再按一次（此時顯示「✕ 收合」）或按 Esc 收合。
- 點名字**開始計時後面板會自動收合**，時鐘再次放大；在「編輯名單」中操作、或點灰色名字恢復為未分享時不會收合。
- 計時中再打開面板，只會看到名單；「每人分享時間」設定要等計時結束才會出現。
- **橫向**（寬 > 高，例如 iPad 橫放、筆電）：面板開啟時時鐘在左、設定與名單在右；超寬螢幕會置中（最寬 1600px）。
- **直向**（任何寬度，包含 13 吋 iPad 直放）：面板開啟時時鐘在上、設定與名單在下（置中，最寬 720px）。

## 功能
- 名單新增、刪除、改名、調整順序（按「編輯名單」）
- 所有人共用一個分享時間（新安裝預設 1:00，範圍 0:05～59:55；已儲存的時間會保留）
- 點名字（或座位）開始計時；點另一個人會自動把前一位標記為「已分享」；點灰色名字／座位可恢復為未分享
- 圓內的「暫停／繼續」、「結束」；名單的「全部重設」
- 座位圖：每人坐 前／右／後／左 其中一邊，座號依邊自動編（可用「座位圖」開關隱藏）
- 別搞混：標題列「全部重設」＝只把已分享狀態清掉，名單保留；「編輯名單」最下方的「成員全部重設」＝清除全部成員與座位（會跳出「是／否」確認視窗；名單為空時無法按）
- 鈴聲以 Web Audio API 即時合成（無音檔）；語音提示使用瀏覽器內建語音合成
- 輸入姓名時支援注音／拼音輸入法（選字的 Enter 不會誤新增或重複新增）
- 計時中使用 Screen Wake Lock 避免螢幕休眠（瀏覽器支援時）
- 名單（含每人坐哪一邊與順序）、時間、已分享狀態、座位圖開關存在 localStorage

## 檔案
```
index.html            主頁面
styles.css            樣式
app.js                程式邏輯
manifest.json         PWA 設定
service-worker.js     離線快取（修改檔案後請調整 CACHE_VERSION）
icons/                App 圖示（已產生，直接提交）；logo.png 為「心成」標誌（由 logo-hd-fixed.png 以 LANCZOS 縮成 400×120）
scripts/make-icons.py 圖示產生程式（需 Pillow，可選）
```

## 本機測試
```sh
python3 -m http.server 8000
# 開啟 http://localhost:8000/
```
Service worker 需要 HTTPS 或 localhost。iPhone 測試請部署到 GitHub Pages 後用 Safari 開啟，
「分享 → 加入主畫面」即可以 App 方式使用。

## 部署到 GitHub Pages
所有路徑皆為相對路徑，可直接放在子路徑（例如 `https://<帳號>.github.io/share-timer/`）。
